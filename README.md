# 🚀 Aprendizaje y Lógica en JavaScript

Hola, soy **Adrián Rosel**, estudiante del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW).

Este repositorio documenta, paso a paso, mi proceso de aprendizaje de JavaScript desde cero: desde los fundamentos básicos hasta conceptos intermedios y avanzados, con el objetivo de construir una base de lógica de programación sólida antes de empezar segundo curso.

## 🧠 100% Lógica Humana (Cero IA)

Todos los ejercicios y resoluciones de este repositorio están programados **sin el uso de Inteligencia Artificial para generar código**. La IA solo interviene, puntualmente, para:

- Corregir un error concreto ya identificado por mí.
- Darme una pista que me ayude a hacer "clic" con un concepto, sin resolver el ejercicio por mí.

El resto —estructurar la lógica, pelear con la sintaxis y depurar bugs— lo hago de forma autónoma. El objetivo no es memorizar soluciones, sino entrenar la capacidad de descomponer y resolver problemas por mí mismo.

## 📚 Curso base

Sigo el curso **[hello-javascript](https://github.com/mouredev/hello-javascript)** de Brais Moure (mouredev), tanto el bloque de fundamentos desde cero como el intermedio. La estructura de lecciones pertenece al curso original; el código, la lógica y las resoluciones de cada ejercicio son míos.

## 🛠️ Metodología de estudio

- **Retrieval practice**: Resuelvo cada ejercicio sin mirar la solucion
- **Documentación oficial primero**: MDN es mi referencia principal ante cualquier duda de sintaxis o comportamiento del lenguaje, antes que preguntar a una IA.
- **Sin autocompletado inteligente**: trabajo sin IntelliSense ni Emmet para forzar la memorización real de sintaxis, no el reconocimiento asistido.
- **Ejercicios propios**: cuando un ejercicio del curso se queda corto, lo amplío por mi cuenta para aplicar conceptos de lecciones anteriores (ver `Basic/32-import-passwd-function.js`).
