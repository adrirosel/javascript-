# 🚀 Aprendizaje y Lógica en JavaScript

Hola, soy **Adrián Rosel**, estudiante actual del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW).

Bienvenido a mi repositorio. Este espacio ha sido creado con el fin de ir documentando, paso a paso, mi proceso de aprendizaje y evolución escribiendo código en JavaScript. 

## 📂 ¿Qué encontrarás aquí?

Al explorar los directorios de este proyecto, te encontrarás con una radiografía directa de mi progreso como programador. El contenido está estructurado para reflejar cómo he ido construyendo y consolidando mi lógica computacional desde cero. 

El repositorio contiene desde scripts básicos y manejo de estructuras de datos, hasta arquitecturas más complejas utilizando funciones avanzadas, modularización y manipulación del entorno. A medida que avanzan los *commits*, el código evidencia la maduración en mi forma de plantear, estructurar y resolver problemas algorítmicos.

## 🧠 100% Lógica Humana (Cero IA)

Es importante destacar un pilar fundamental de este repositorio: **todos y cada uno de los ejercicios, prácticas y resoluciones lógicas han sido programados estrictamente sin el uso de Inteligencia Artificial**. 

El código que hay aquí es el resultado de pelear con la sintaxis, estructurar la lógica a mano y resolver los *bugs* de forma autónoma para asentar una base técnica real y sólida en el ecosistema de JavaScript.
